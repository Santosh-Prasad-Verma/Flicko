# Contributing to Flicko

Thanks for your interest in contributing! Please follow these simple steps:

1. Fork the repository and create a branch from `main` (e.g. `feature/my-change`).
2. Install dependencies: `npm ci`.
3. Run lint: `npm run lint` and ensure there are no errors.
4. Build locally: `npm run build`.
5. Open a pull request describing your changes and link related issues.

Commit message guidance: use short, descriptive messages (Conventional Commits are recommended).

Maintainers will review and provide feedback. Thank you!
