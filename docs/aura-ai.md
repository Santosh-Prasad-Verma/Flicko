# Flicko Aura AI Assistant

## Overview
Aura AI is the integrated, intelligent companion within the Flicko ecosystem. It serves as a centralized hub for generative AI features, providing users with specialized tools like a Text Writer, Image Generator, and Code Tutor. Aura provides an immersive, retro-futuristic chat interface that can run via a local simulation engine or connect live to the Google Gemini API.

## Architecture & State Management
- **State Management**: Built with Riverpod (`flutter_riverpod`). The `auraSessionsProvider` inside `/lib/features/ai_assistant/data/aura_chat_service.dart` handles the persistence and state of chat sessions, messages, and API keys.
- **API Integration**: Supports live integration with the Gemini API. Users can input their own `AIzaSy...` key in the dashboard to switch from the local simulated engine to live generative AI responses.

## Core Features & Screens
1. **Aura Dashboard (`aura_dashboard_screen.dart`)**
   - **Search & History**: Users can search past queries and manage their conversation history.
   - **Quick Tools**: Entry points to start specific session categories:
     - *Text Writer* (Pink theme)
     - *Image Generator* (Purple theme)
     - *Code Tutor* (Cyan theme)
   - **Voice Activation**: A prominent "TALK TO AURA" FAB routes users to the voice interface (`/profile/settings/aura/voice`).
2. **Aura Chat Interface (`aura_chat_screen.dart`)**
   - **Dynamic Theming**: The chat interface's accent color changes based on the active tool category (e.g., Cyan for Code Tutor).
   - **Rich Media Support**: Displays generated images natively with a tap-to-expand `AuraImageViewerScreen`.
   - **Code Sandbox (`AuraSandboxScreen`)**: When Aura generates code blocks (```...```), a "RUN PREVIEW" button appears, allowing users to execute or preview the code in a sandbox environment.
   - **Interactive Messages**: Includes actions to copy text, provide feedback (like/dislike), regenerate responses, and toggle simulated Text-to-Speech (TTS) readout with wiggling animations.
   - **Typing Indicators**: Animated typing indicators and scrolling mechanics ensure a natural conversational feel.

## Design Aesthetic
- **Color Palette**: Utilizes deep blacks (`#050505`, `#141418`) contrasted against vibrant neon accents like Pink (`#xFFFF007F`), Purple (`#FF8B00FF`), and Cyan (`#FF00FFCC`).
- **Typography**: Employs `GoogleFonts.spaceGrotesk` for primary text and `GoogleFonts.epilogue` for large, bold headers, alongside `spaceMono` for code and metadata.
- **Animations**: Heavy use of `flutter_animate` for smooth transitions, fades, slides, and interactive feedback (like the wiggling TTS icon or the pulsing typing dots).

## Future Projections & Roadmap
- **Live Voice Interaction**: Fully integrate bidirectional voice streaming (e.g., using Gemini Live API or similar WebRTC solutions) for natural, spoken conversations with Aura.
- **Contextual App Awareness**: Allow Aura to read the user's current Flicko state (e.g., knowing what song they are listening to in Sonic Drip or what cosmetics they own) to provide hyper-personalized recommendations.
- **Cloud Persistence**: Move session history from local storage to the Supabase backend to synchronize AI conversations across multiple devices.
- **Advanced Sandbox**: Expand the `AuraSandboxScreen` to compile and render more complex Flutter widgets or external web snippets generated by the Code Tutor.
