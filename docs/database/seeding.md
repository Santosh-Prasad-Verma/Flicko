# Database Seeding

## Seed Script
File: `supabase/seed.js` (7.3 KB)

Run seeding:
```bash
node supabase/seed.js
```

## Reset Script
File: `supabase/reset.js` (4.2 KB)

Reset database:
```bash
node supabase/reset.js
```

This drops and recreates all tables, then runs seed data.
