# Changelog

All notable changes to the Flicko Mobile project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-24

### Added
- Complete Flutter migration from React Native/Expo.
- Modular "Feature-First" architecture implementation.
- Advanced Server Management (Roles, Channels, Audit Logs).
- Moderation Hub (Timeouts, Bans, AutoMod).
- Premium Features (Flicko Plus, Stripe Integration).
- Social Features (Polls, Stickers, Shared Whiteboard).
- Production-ready UX polish (Haptics, Gesture Guide).
- Multi-language support (English, Spanish).
